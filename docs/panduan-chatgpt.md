# Mengambil logo Solo Harmony dari ChatGPT

Tujuan panduan ini adalah membantu staf mengambil logo yang sesuai unit bisnis
tanpa harus mencari ulang di Drive atau meminta file melalui chat.

## Jalur GitHub

1. Pada akun ChatGPT yang dipakai kantor, buka pengaturan aplikasi atau koneksi.
2. Sambungkan aplikasi GitHub melalui alur login resmi jika belum tersambung.
3. Jika pemilihan repo tersedia, izinkan akses ke `arizaltp-afk/solo-harmony-brand-assets`.
4. Mulai chat dengan GitHub aktif, lalu minta ChatGPT membaca `README.md` dan
   `CATALOG.md` pada repo tersebut. Nama menu dapat berbeda sesuai akun atau versi aplikasi.
5. Sebutkan unit dan tujuan: Furniture, Renovation, atau Industries / Office;
   misalnya profil, proposal, watermark, atau sponsor.

Tanda berhasil: ChatGPT menyebut nama berkas yang benar, menemukan dimensinya,
dan memberikan tautan `raw.githubusercontent.com` yang cocok dengan katalog.
Membaca katalog saja belum membuktikan bahwa gambar sudah dimasukkan ke dokumen;
buka hasil dokumen dan periksa logo yang benar-benar terpasang.

## Jalur tautan publik

Jika koneksi GitHub belum tersedia, gunakan chat yang dapat membuka tautan web dan
berikan salah satu tautan berikut:

- Repo: https://github.com/arizaltp-afk/solo-harmony-brand-assets
- Katalog: https://raw.githubusercontent.com/arizaltp-afk/solo-harmony-brand-assets/main/CATALOG.md
- Manifest: https://raw.githubusercontent.com/arizaltp-afk/solo-harmony-brand-assets/main/manifest.json
- Indeks AI: https://raw.githubusercontent.com/arizaltp-afk/solo-harmony-brand-assets/main/llms.txt

Contoh permintaan siap pakai:

> Gunakan pustaka logo publik Solo Harmony di
> https://github.com/arizaltp-afk/solo-harmony-brand-assets.
> Baca CATALOG.md, lalu ambil logo Industries / Office PNG transparan untuk dokumen
> kantor. Gunakan berkas asli melalui tautan raw, tanpa menggambar ulang atau
> mengubah warna dan proporsi. Sebutkan nama file, ukuran, dan tautan sumber.

Untuk pekerjaan Furniture atau Renov, ganti unit dan kebutuhan pada contoh itu.
Jika menggunakan Project atau GPT khusus kantor, simpan tautan katalog dalam
petunjuk proyek/GPT agar mudah dirujuk. Salinan file yang diunggah sebagai knowledge
adalah snapshot dan tidak otomatis mengikuti pembaruan repo.

## Memilih dan memasang logo

- Kantor / Office menggunakan identitas **Solo Harmony Industries**.
- Profil Furniture bulat kuning tersedia paling besar dalam WebP 1080 x 1080.
  Alternatif JPG berukuran 540 x 540 dan PNG transparan berukuran 210 x 210.
- Watermark Furniture tersedia sebagai PNG transparan 2172 x 724.
- Furniture putih transparan cocok untuk latar gelap.
- Renov hijau tersedia 150 x 150; jangan diperbesar untuk cetak besar.
- Renov putih adalah JPG dengan latar hitam yang menyatu dengan gambar.
- Gunakan rasio asli. Jangan mengetik ulang tulisan atau mengganti bentuk simbol.

## Jika belum terbaca

Repo baru bisa belum muncul pada hasil pencarian. Buka URL repo atau katalog
secara langsung, atau periksa apakah GitHub sudah mengizinkan repo itu. Untuk
koneksi yang membatasi repo terpilih, pemilihan dilakukan melalui pengaturan resmi
pada akun yang bersangkutan.

Jika chat tidak mempunyai akses web/GitHub, buka katalog sendiri lalu unduh dan
lampirkan berkas logo yang diperlukan. Jika konektor hanya membaca teks, gunakan
tautan raw dari katalog untuk mengambil gambarnya dengan alat dokumen yang tersedia.

Repo ini telah disiapkan sebagai sumber publik. Konfigurasi serta keberhasilan
pembacaan pada akun ChatGPT kantor yang berbeda perlu diperiksa pada akun tersebut.
