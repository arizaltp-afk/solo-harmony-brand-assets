## Catatan per varian

- **furniture-original-color**: Ekspor PNG lama dari arsip pemilik; bukan master vektor.
- **furniture-original-white**: Seluruh tulisan dan simbol berwarna putih; gunakan latar gelap.
- **furniture-circle-1080**: Nama sumber berakhiran .jpg, tetapi isi sebenarnya WebP. Ekstensi disesuaikan tanpa mengubah byte.
- **furniture-circle-540**: Salinan identik juga ditemukan pada aset preview milik pemilik.
- **furniture-circle-210**: Resolusi kecil; jangan diperbesar untuk cetak.
- **furniture-circle-web-210**: File sumber logo_bulat.png sebenarnya JPEG. Byte asli dipertahankan; ekstensi menjadi .jpg. Cocokkan bentuk dengan sumber resolusi besar.
- **furniture-wordmark-transparent**: Ekspor Canva milik pemilik. Piksel sama dengan versi aplikasi; encoding file berbeda.
- **furniture-wordmark-app**: Piksel sama dengan ekspor wordmark transparan. Disimpan untuk kecocokan byte dengan aplikasi.
- **furniture-wordmark-white**: Ekspor yang sudah tersedia; tidak dipotong atau digambar ulang.
- **renovation-circle**: Resolusi hanya 150x150. File hijau resolusi besar belum ditemukan.
- **renovation-circle-jpg**: Arsip JPG beresolusi kecil; pilih PNG untuk profil dengan transparansi.
- **renovation-white**: File JPG memiliki latar hitam permanen; bukan logo transparan. Rekaman Drive dibuat 2023, versi sekarang diperbarui 2026.
- **industries-circle-2000**: Ekspor Canva pemilik, kanvas luar putih permanen.
- **industries-square-1536**: Ekspor Canva yang sudah tersedia.
- **industries-office-1024**: Nama file aplikasi menyebut Office, tetapi identitas yang tercetak adalah Solo Harmony Industries.
- **industries-small-150**: Arsip kecil; gunakan ekspor resolusi besar untuk materi baru.
- **office-icon-192**: Turunan ikon aplikasi; gunakan katalog logo untuk dokumen, profil, atau promosi.
- **office-icon-512**: Turunan ikon aplikasi; gunakan katalog logo untuk dokumen, profil, atau promosi.
- **office-icon-512-maskable**: Turunan ikon aplikasi; gunakan katalog logo untuk dokumen, profil, atau promosi.
- **office-apple-touch-icon**: Turunan ikon aplikasi; gunakan katalog logo untuk dokumen, profil, atau promosi.
- **furniture-favicon**: Simbol rumah sederhana untuk tab browser; bukan master vektor logo merek.
- **renovation-favicon**: Simbol rumah sederhana untuk tab browser; bukan master vektor logo merek.

Data lengkap, SHA-256, transparansi aktual, tautan publik, dan nama sumber ada di [manifest.json](manifest.json).
